# VCP ドキュメント

VCP (Virtual Cloud Provider) は、クラウド上に計算資源を確保し、コンテナによる実行環境を構築・運用するためのソフトウェアです。Jupyter Notebook から VCP SDK を呼び出すことで、複数のクラウドプロバイダにまたがる計算環境をコードとして構築できます。

---

## はじめての方へ

VCP を利用するには、まず **VC コントローラ**を機関内に構築し (VC 管理者の作業)、その上で **VC ノード**を起動します (VC 利用者の作業)。それぞれの役割に応じて、以下から読み進めてください。

| 読者 | 最初に読むもの |
|---|---|
| VCP がどのようなものか知りたい | [コンセプト](concepts/README.md) |
| 機関に VCP 環境を構築したい (VC 管理者) | [はじめる: VCP 環境を構築する](getting-started/setup.md) |
| 構築済みの環境で計算資源を使いたい (VC 利用者) | [はじめる: 最初の VC ノードを起動する](getting-started/first-node.md) |
| 講義環境や HPC クラスタを構築したい | [アプリケーションテンプレート](templates/README.md) |

## ドキュメント一覧

### [コンセプト](concepts/README.md)

VCP の基本的な考え方と構成要素を説明します。VC / UnitGroup / Unit / VC ノードといった単位、compute・storage の種別、ベースコンテナとアプリケーションコンテナの関係など、以降のドキュメントを読む前提となる概念を扱います。

### [はじめる](getting-started/README.md)

VCP を最小構成で動かすまでの手順です。読者の役割に応じて 2 つに分かれています。

- [1. VCP 環境を構築する (VC 管理者向け)](getting-started/setup.md) — VC コントローラを機関内に構築します。必要なリソース、クラウド側の事前準備、構築の全体像と完了確認の方法を説明します。
- [2. 最初の VC ノードを起動する (VC 利用者向け)](getting-started/first-node.md) — 構築済みの環境で、Notebook から VC を作成し、VC ノードを 1 台起動して削除するまでを通して実行します。

構成の選択肢は扱わず、単一の経路のみを示します。GPU の利用や複数プロバイダの組み合わせなどは[チュートリアル](tutorials/README.md)を参照してください。

### [チュートリアル](tutorials/README.md)

基本構成以外の使い方を扱います。GPU インスタンスの利用など、目的別の手順をまとめています。あわせて、OCS で実施したハンズオン資料への索引を提供します (これらはサービス提供当時の記録であり、現行の手順とは異なる場合があります)。

### [運用ガイド](operations/README.md)

構築した VCP 環境を継続して運用するための情報です。コンテナレジストリ、秘密情報管理サーバ、情報収集・可視化といった VC コントローラの各機能の運用方法に加え、アップデート、バックアップ、証明書の管理などを扱います。

### [SDK リファレンス](sdk/README.md)

VCP SDK の API 仕様です。SDK の機能仕様とシステム設計、クラウドプロバイダプラグイン、VCP LIB、CLI の操作方法を収録しています。

### [ベースコンテナ仕様書](specs/base-container.md)

VC ノードとして動作するコンテナイメージが満たすべき要件を定めた仕様です。ベースコンテナを新たに作成する場合や、既存のベースコンテナを改修する場合に参照してください。

### [アプリケーションテンプレート](templates/README.md)

VCP 上に特定のアプリケーション環境を構築するための Notebook 群です。講義演習環境 (CoursewareHub)、HPC クラスタ (OpenHPC)、LMS (Moodle) などのテンプレートが公開されています。

### [FAQ・サポートポリシー](support/README.md)

よくある質問と、サポートの範囲・問い合わせ方法についての方針を記載しています。
