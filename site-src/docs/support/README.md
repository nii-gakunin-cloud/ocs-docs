## お問い合わせ { #お問い合わせ }

FAQ で解決しない場合は、下記の窓口までお問い合わせください。

国立情報学研究所 クラウド支援室 学認クラウドオンデマンド構築サービスサポート窓口:
[cld-ocs-support@nii.ac.jp](mailto:cld-ocs-support@nii.ac.jp)

お問い合わせの際は、以下の情報を添えていただくと調査がスムーズになります。

- 使用しているテンプレートと、問題が発生した Notebook・セル
- エラーメッセージの全文
- 構築先のクラウドプロバイダと VCP SDK のバージョン

CoursewareHub 構築時の問題については、
[情報収集用の Notebook](https://nii-gakunin-cloud.github.io/ocs-docs/faq/ocs-template/CousewareHub構築時の問題分析のための情報収集.ipynb)
を用意しています。実行結果を保存したファイルも添付してください。
