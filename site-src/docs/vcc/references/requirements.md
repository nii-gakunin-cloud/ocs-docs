# 要件一覧

VCコントローラが求めるマシン等の要件について記載する。  

## オンプレミスマシンの要件

VCコントローラから起動する、VCノードとして利用するためのマシンの要件を記載する。  

- Ubuntuマシンであること
- SSHログインしてVCノードに利用するユーザ（デフォルトでは `ubuntu`）が、パスワード無しで `sudo` コマンドを利用可能であること
- VCコントローラの鍵ペア（`/opt/occ/.ssh/id_ed25519`）で、20022番ポート経由でのSSHログインが可能
- docker が利用可能

> [!NOTE]
> オンプレミス(既存サーバ)を除く、VCPがサポートするクラウドプロバイダについては、VCコントローラが、マシン起動とこれらの条件を満たすためのセットアップを自動で行う。

## 利用するベースコンテナの要件

VCコントローラが起動したマシン上で稼働するベースコンテナのコンテナイメージの要件について記載する。  
ここでは、最低限ベースコンテナが起動し、この死活監視をVCコントローラが行うために最低限必要なものを「必須」としている。  
したがって、ベースコンテナがの用途は考慮しない。（用途に合わせたベースコンテナイメージを各自が作成する。）  

- 必須
    - sshd が 22 番ポートで稼働している
    - serf が 7947 番ポートで稼働している
        - 以下の環境変数がVCコントローラによってコンテナ起動オプションに設定される
            - SERF_NODE_ID: ノードのID `{UnitGroup ID}:{Unit 名}:{ノード番号}`
            - PRIVATE_IP: マシンのプライベートIPアドレス
            - VCCC_ID: UnitGroup ID （本来VC_IDであるべきだが、VCCC_IDとなっているため、VCコントローラのIDと間違えないよう注意）
            - VCCCTR_IPADDR: VCコントローラが稼働するマシンのプライベートIPアドレス
- 任意
    - 環境変数 `AUTHORIZED_KEYS` に指定したSSHログイン用公開鍵（base64エンコード済）を利用可能にする  

        標準的な構成では、構築用jupyter環境からVCノードの起動を行うため、構築用jupyter環境からSSHログイン可能であることが必要。
