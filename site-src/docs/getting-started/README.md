# はじめる

VCP を最小構成で動かすまでの手順です。

VCP の利用は、**VC コントローラを構築する**作業と、**構築された環境で VC ノードを起動する**作業に分かれます。担当する人が異なる場合もあるため、以下の 2 つのページに分けています。

| ページ | 対象 | 内容 |
|---|---|---|
| [1. VCP 環境を構築する](setup.md) | VC 管理者 | VC コントローラを機関内に構築します。機関で 1 回だけ行う作業です。 |
| [2. 最初の VC ノードを起動する](first-node.md) | VC 利用者 | 構築済みの環境で、Notebook から VC ノードを起動・削除します。 |

すでに VC コントローラが構築されている環境を利用する場合は、[2](first-node.md) から始めてください。

用語や全体の構成については[コンセプト](../concepts/README.md)を参照してください。
