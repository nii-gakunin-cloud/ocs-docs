# 2. 最初の VC ノードを起動する (VC 利用者向け)

Notebook から VC ノードを 1 台起動し、削除するまでを実行します。VCP の基本的な操作を一通り確認できます。

---

## 前提条件

- VC コントローラが構築済みであること ([1. VCP 環境を構築する](setup.md))
- Notebook 環境にログインでき、SDK の初期設定が完了していること
- VC ノードを起動するクラウドプロバイダの認証情報が登録されていること

操作は、VC コントローラと一緒に導入された Notebook 環境で行います。VCP SDK が組み込まれているため、追加の準備は必要ありません。

---

## 手順

VC ノードの起動と削除の手順は、以下の資料で説明されています。

### 解説資料

**[VC ノードの起動、削除 (ユーザーズマニュアル)](https://nii-gakunin-cloud.github.io/ocs-docs/usermanual/101_manual.html)**

実行結果を含む形で手順を説明した資料です。まずはこちらを読み、どのような操作を行うのかを把握してください。

同じ内容を、各ステップの実行の様子を収録した動画付きで公開しています。あわせて参照してください。

- [101 VC ノードの起動、削除 (自習用資料)](http://tutorials.vcp-handson.org/101.html)

### Notebook

実行可能な Notebook は、ハンズオンの教材として公開されているものを利用できます。

- [基礎編 教材 (2024年2月版)](https://github.com/nii-gakunin-cloud/handson/blob/master/Basic-Tutorials/handson202402-vcp)

> **注意**
>
> これらの Notebook は、**ハンズオンセミナーで用意された環境で実行することを前提に作成されています。**そのままでは自分の環境で動作しません。実行する前に、少なくとも以下の点を自分の環境に合わせて書き換えてください。
>
> - **接続先と認証情報** — VC コントローラの接続先や、クラウドプロバイダの認証情報の指定。
> - **クラウドプロバイダとインスタンスの指定** — 使用するプロバイダ、リージョン、インスタンスの種別。ハンズオンで使用したものが自分の環境で利用できるとは限りません。
> - **ネットワーク関連の設定** — 環境に応じた設定が必要になる場合があります。
> - **名称** — VC やノードの名前が、ハンズオン用のものになっている場合があります。

---

## 実行する内容

一連の流れは次のとおりです。

| 手順 | 内容 |
|---|---|
| 1. SDK の準備 | Notebook から VCP SDK を読み込み、VC コントローラに接続します。 |
| 2. VC の作成 | VC ノードを配置する VC を作成します。 |
| 3. VC ノードの起動 | 計算資源を 1 台確保し、VC ノードとして起動します。 |
| 4. 動作の確認 | 起動した VC ノードに接続し、コンテナが動作していることを確認します。 |
| 5. 削除 | 起動した VC ノードを削除します。 |

VC ノードはクラウド上の計算資源を使用します。**確認が終わったら、必ず削除してください。**起動したままにすると、クラウドプロバイダの利用料金が発生し続けます。

---

## 完了の確認

VC ノードが起動し、接続でき、削除まで完了すれば、VCP の環境は正しく動作しています。
