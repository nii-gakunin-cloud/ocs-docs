# ベースコンテナ仕様書

ベースコンテナは、VC ノードとして確保した計算資源の上で VCP が起動するコンテナです。VC ノードとしての
基本的な機能を提供し、VC コントローラとの通信を担います。

このページは仕様書への入口です。仕様の本体は[ベースコンテナ](../basecontainer/index.md)にあります。

---

## この仕様書が必要になる場合

以下のいずれかに該当する場合に参照してください。

- 独自のベースコンテナイメージを作成する
- 既存のベースコンテナイメージを改修する
- アプリケーションテンプレート向けに専用のベースコンテナを用意する

**通常の利用では読む必要はありません。**VC ノードを起動してアプリケーションを動かす場合、
ベースコンテナは VC コントローラによって自動的に起動されるため、利用者が直接操作することは
ありません。ベースコンテナの概念については[コンセプト](../concepts/README.md)を参照してください。

---

## VC コントローラとの関係

ベースコンテナは、VC コントローラから見た「VC ノードとして成立する条件」を満たす必要があります。
仕様のうち、特にこの条件に関わるのは以下の部分です。

- **起動コマンド** — VC コントローラがどのようなオプションと環境変数を与えて起動するか
- **環境変数** — VC コントローラが設定する値をイメージ側がどう扱うか
- **死活監視** — VC コントローラが VC ノードを認識し続けるための仕組み

独自のイメージを作成する場合は、これらを満たしているかを確認してください。
