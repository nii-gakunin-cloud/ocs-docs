# SDK リファレンス

VCP SDK は、Jupyter Notebook から VCP を操作するための Python ライブラリです。VC の作成、VC ノードの
起動と削除、ストレージの割り当てといった操作を行います。

SDK は VC コントローラと一緒に導入される Notebook 環境に組み込まれているため、個別に導入する
必要はありません。
